## Content

* Biotransformation\_k\_R/
Contains R scripts (tested on R version 4.4.3) and input data used to reproduce the derivation of biotransformation rate constants from measured concentration–time series. The folder also includes the subsequent data analysis, visualizations, and multivariate statistics. Additional experimental data visualisation accomplish the folder. Script files are numbered in the order in which they should be executed.
* Amplicon\_analysis/
Contains scripts and data required to reproduce the analysis and visualization of the 16S rRNA amplicon sequencing results.
* Metagenomic\_analysis/
* k\_MK\_6WWTPs\_3tech.xlsx
A machine-readable Excel file containing all derived rate constants along with the corresponding experimental metadata.
